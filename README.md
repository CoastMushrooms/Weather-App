# Weather App

Weather app built for the PM Acclerator technical assesment (Technical Assesment 1 - Frontend)

Built by Urvi Akhouri

## Features

- Search for current weather by city
- Get weather for current location (geolocation)
- Get a 5-day forecast
- Format adjusts to screen layout

## Tech Implemented

- React (via Vite)
- OpenWeatherMap API (Responsible for data)

## Running Locally

1. Clone this repo:

```git clone [your repo URL]
cd WeatherApp```

2. Install dependencies

```npm install```

3. Create an `.env` file in the project with your own OpenWeather API key:

You can get a key by registering at https://openweathermap.org/api

4. Start the dev server:

```npm run dev```

5. Open http://localhost:5173 in your browser
